# Mathematics-of-AI
Notebooks exploring the mathematical foundations of AI and neural networks.



## Contents

|  | Folder | Topics |
|---|--------|--------|
| 1 | `Intro to Deep Learning using Keras` | Feedforward networks, MNIST classification, Keras + JAX |
| 2 | `Singular Value Decomposition & Intro to NumPy.` | SVD, matrix factorization, NumPy arrays and operations |
| 3 | `Machine Learning Basics` | SGD, bias-variance tradeoff, double descent, SVMs, kernel trick |
| 4 | `Overview of Deep Network architectures` | Forward pass, activation functions, backpropagation, CNNs, RNNs, Transformers |
| 5 | `Generative Models` | VAEs, ELBO, GANs, diffusion models, score-based generation, sequence & memory models |
| 6 | `Geometric Deep Learning` | Symmetry groups, equivariance, graph neural networks |
| 7 | `Reinforcement Learning` | MDPs, Bellman equations, policy gradients, RLHF |
